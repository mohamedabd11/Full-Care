# فل كير (Full Care)

تطبيق العناية اليومية والجمال للمرأة السودانية — واجهة عربية بالكامل (RTL).

يضم: أنظمة عناية عامة مجانية (وجه، جسم، شعر، تمارين، عادات، دخان وخلطات)
وباقة مدفوعة "حَبْسَة العروس" بخمس مراحل.

## التقنيات

- **Expo + React Native + TypeScript**
- **Expo Router** للتنقل (تبويبات سفلية)
- **NativeWind** للتنسيق (Tailwind)
- **Supabase** لقاعدة البيانات والمصادقة والتخزين
- خط **Cairo** العربي، اتجاه RTL مفروض

## التشغيل محلياً

1. ثبّت الحزم:
   ```bash
   npm install
   ```
2. أنشئ ملف `.env` من القالب واملأ مفاتيح Supabase:
   ```bash
   cp .env.example .env
   ```
   > استخدم مفتاح **anon / publishable** فقط — لا تضع مفتاح `service_role` السري إطلاقاً.
3. شغّل المشروع:
   ```bash
   npx expo start
   ```
   افتح التطبيق عبر تطبيق **Expo Go** على هاتفك (امسح رمز QR).

## بنية المشروع

```
app/                  شاشات Expo Router
  _layout.tsx         الجذر: فرض RTL + تحميل الخطوط
  (tabs)/             التبويبات السفلية
    _layout.tsx       شريط التبويبات (الرئيسية، الأنظمة، الحَبْسَة، حسابي)
    index.tsx         الرئيسية
    systems.tsx       الأنظمة الستة
    habsa.tsx         حبسة العروس
    account.tsx       حسابي
src/
  components/         مكوّنات مشتركة (AppText, Screen)
  data/              بيانات الأنظمة
  lib/supabase.ts    عميل Supabase
  theme/colors.ts    ألوان الهوية البصرية
content/              هيكل المحتوى (JSON)
docs/                قاعدة المعرفة والقرارات
```

## حالة التطوير

- ✅ الخطوة 1: إعداد المشروع + RTL + الهوية البصرية + التنقل + شاشات أولية
- ⬜ الخطوة 2: محرك الحَبْسَة (habsaEngine)
- ⬜ الخطوات 3–7: شاشات الحبسة، التحفيز، محتوى الأنظمة، تكامل Supabase، التلميع
